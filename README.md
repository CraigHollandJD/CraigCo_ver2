# CrAIgCo — ChatGPT Design Version 2

Standalone copy of the ChatGPT Sites design, exported October 30, 2026.

Copy all extracted files and the assets folder to the root of a separate repository. Enable GitHub Pages from main / (root).

Files: index.html (page), styles.css (design), app.js (interactions), assets/ (images and animation).

Content Studio changes are saved in the current browser; export a content plan to back them up. Browser-specific edits are not included in this source export.

The original design contains “private” and “owner access” labels. These are display text, not access controls on GitHub Pages. GitHub Pages publication may be public.
